# YouTube Homepage Clone (Static)

This is a **static clone of the YouTube homepage** built using **HTML and CSS**.  
It recreates the layout of YouTube’s landing page, including the header, sidebar, and a grid of video previews with thumbnails, channel info, and tooltips.

---

## Live Demo
**_https://youtube-homepage-ten.vercel.app/_**

---

## Project Structure

```bash
.
├── index.html
├── styles/
│   ├── general.css
│   ├── header.css
│   ├── sidebar.css
│   └── video.css
└── assets/
    ├── icons/
    ├── thumbnails/
    └── channel-pictures/
```

---

## Technologies Used

- **HTML5**
- **CSS3**

---

## Features

### Layout
- Fixed header  
- Sidebar navigation  
- Responsive video grid

### UI Elements
- Hover tooltips  
- Notification badge  
- Custom favicon

### Responsiveness
- Media queries for different screen sizes

---

## How to Run Locally

1. Clone or download the project  
2. Open `index.html` in any web browser  
3. Ensure the `assets/` and `styles/` folders stay in the same directory structure
